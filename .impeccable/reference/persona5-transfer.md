# Persona 5 → EMO RUSH: what carries over

Source: `persona5-dna.json` (design-dna extraction from four user-supplied screenshots, 2026-11-17).
Persona 5 sets the craft bar. It does not set the look. EMO RUSH is shown in public at ITB Insight 2026, so nothing here may read as a Persona 5 copy.

## Take (structure and numbers)

| Principle | Persona 5 value | EMO RUSH rule |
|---|---|---|
| Contrast | Black, white, one saturated colour; no mid-tone UI surfaces | One dominant brand colour + black + white. Emotion colours appear only on the active item. |
| Scale jumps | Display ≈ 10× body; selected item ≈ 1.3× unselected | Interrupt words (grade, LULUS, countdown) 280–320 px at 1080p; selected menu item 1.3× the rest; body text never under 26 px (read from 3 m). |
| Diagonal | Menu stepped on a 15–25° diagonal; art owns the opposite third | One diagonal per screen; the live camera owns the opposite side. |
| Overlap | Items overlap 10–30% of their height | Paper strips and labels overlap; nothing floats in its own box. |
| Selection | Selected item inverts, grows, gets a shape behind it | Same mechanics, with the chosen world's material as the shape behind. |
| Depth | Hard duplicate slab behind, zero blur | Allowed only if the world's material has it (a paper strip's real shadow is soft, so a mading uses soft paper shadow, not offset slabs). |
| Motion | Micro 80–120 ms, normal 200–300 ms, macro 500–800 ms; slam with overshoot; hard cuts | Same timing budget; one slam per confirmation; screen changes are cuts or one wipe. |
| One focal word | Each screen has one hero element | Each phase has exactly one: the camera, the countdown digit, or the grade. |

## Replace (Persona 5's signature → EMO RUSH's own)

| Persona 5 signature | EMO RUSH replacement |
|---|---|
| Signal red #F12525 / deep red #8A0C06 | ITB Insight royal blue #1B23C9 as the dominant field |
| Ransom-note letters, each glyph a different face | One licensed display family (condensed width axis) set on material from the chosen world |
| Stars, skulls, calling cards | Objects from the chosen world (for a mading: pins, tape, stabilo, stamps) |
| Spectral glitch band behind selection | The four colours of the ITB Insight star logo, one per emotion group |
| Anime character art | The player's own live camera image |
| Speech bubbles with portrait | Lines in the chosen world's voice (MC line, notice on the board) |

## Never

- Red-black-white as the main palette, ransom-note mixed lettering, star or skull motifs, the calling-card shape, Persona 5 fonts or fan recreations of them, or any Persona 5 character, name or screenshot in the game or its assets.
